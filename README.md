# RoamView
RoamView is a dual-mode robotic platform that gives remote stakeholders accurate, live, and interactive access to any  physical space without requiring anyone to be there in person.

## Repository layout
- `hardware/`: firmware, the ROS 2 simulation, KiCad and datasheets (see `hardware/README.md`).
- `hardware/RobotCAD/`: the SOLIDWORKS robot CAD (start at `hardware/RobotCAD/00_Admin/README.md`). The CAD files are stored with Git LFS, so run `git lfs install` once before cloning.
